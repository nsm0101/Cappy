# OLD — superseded material. Do not file.

Kept for the record only. Nothing here should be attached to a filing.

## `Provisional_Application_Drawings_2026-08-21.pdf`

The previous 11-sheet set (FIG. 1–12). Replaced by
`../Provisional_Application_Drawings.pdf`.

Retired for two reasons:

1. **Scale.** Token 120 and recess 116 were drawn at 0.424 (FIG. 1) and 0.294
   (FIG. 2) of the base outside diameter, against a true value of 0.902 —
   2.1× to 3.1× too small in diameter. The seated token read as a small
   central button instead of a disc filling the underside of the base.
2. **37 CFR 1.84.** Text ran as small as 5.2 pt against a 1/8 in minimum;
   zero-width hairline strokes; sheet 2 left margin 68.2 pt against the 72 pt
   requirement; a dozen embedded Type 3 fonts; no sheet numbers.

Its reference numerals were correct and have been carried forward unchanged.

## `Puck_provisional_figures.pdf`

An earlier 4-sheet set using a different and now-conflicting numbering scheme
(100/110/120/130/140/150 for the token, 200/210/220/230 for the vessel). The
surviving set numbers the vessel 110 and the token 120, so these two schemes
cannot both be referenced by one specification. Superseded in full — every
view it contained appears in the current set under the surviving numerals.
